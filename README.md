# information-retrieval-weighted-jaccard
Sistem Temu Balik Informasi berbasis Streamlit menggunakan algoritma Nazief &amp; Adriani dan Weighted Jaccard Similarity

## Features
- Case Folding
- Tokenizing
- Stopword Removal
- Stemming Nazief & Adriani
- Ranking Dokumen

## How to Run
pip install -r requirements.txt
python -m streamlit run ui/app.py
